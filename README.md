# FromScratchStudy

『ゼロから作るDeep Learning』シリーズを題材に、
深層学習・ニューラルネットワークの仕組みを
コードを実装しながら学習するためのリポジトリです。

## Purpose

ライブラリを利用するだけではなく、
計算グラフ、自動微分、ニューラルネットワークなどの仕組みを
自分で実装することで理解することを目的としています。

## Contents

- Python / NumPy
- Variable / Function
- Computational Graph
- Automatic Differentiation
- Neural Network
- Deep Learning

現在も継続して学習・実装しています。

## Environment

- Python
- NumPy
- macOS
- Visual Studio Code
